# 공식 분양 랜딩페이지 (The Central Le Blanc)

`https://aptdm.kr/` (전환형 DB 접수 시스템)과 `https://www.lottecastle.co.kr/` (롯데캐슬 프리미엄 공식 아이덴티티)의 장점을 결합한 고신뢰 반응형 분양 랜딩페이지입니다.

---

## 🚀 지금 바로 화면 확인하는 방법 (무설치)

1. 폴더 안에 있는 **`index.html`** 파일을 더블클릭합니다.
2. Chrome, Edge, Safari 등 웹 브라우저에서 바로 반응형 디자인과 인터랙션(모바일 스티키 바, 평면도 탭, 관심고객 등록 모달 등)을 확인하실 수 있습니다.
3. 브라우저에서 `F12`를 누른 뒤 모바일 뷰로 전환하시면 스마트폰 화면 최적화 상태도 바로 테스트하실 수 있습니다.

---

## 📁 주요 구성 및 기능

1. **상단 탑바 & 공식 GNB**
   - 신탁/시공 보증 문구, 공식 대표번호(1599-3554), 관심고객 바로가기
2. **히어로 섹션**
   - 프리미엄 야경 조감도 비주얼
   - 오픈 D-Day 실시간 카운트다운 타이머
   - 퀵 관심고객 신청 미니 폼
3. **사업개요 (Overview)**
   - 1군 건설사 공식 규격 표 형태의 건축/공급 세부 정보
4. **프리미엄 6대 핵심가치**
   - 초역세권, 명문학군, 공원라이프, 생활인프라, 미래비전, 하이엔드 커뮤니티
5. **단지 배치도 & 커뮤니티**
   - V자형 배치도, 피트니스, 골프클럽, 스카이라운지, 북카페
6. **타입별 세대 평면안내**
   - 84㎡A / 84㎡B / 59㎡A / 114㎡ 펜트하우스 탭 전환 시스템
7. **입지 및 오시는 길**
   - 주택전시관 지도 및 주소 1초 복사 버튼
8. **관심고객 등록 폼 (Main DB Form)**
   - 고객 성함, 연락처, 희망타입, 방문일자, 개인정보 수집 및 이용 동의 팝업
9. **모바일 전용 하단 고정 스티키 바 (Mobile Sticky CTA)**
   - [전화상담 연결] [관심고객 등록] 즉시 실행 버튼

## ⚡ Next.js 14 환경으로 실행할 때 (`nextjs-template/`)

Next.js 프로젝트로 배포하거나 빌드하려면 Node.js 설치 후 아래 명령어를 입력하시면 됩니다:

```bash
cd nextjs-template
npm install
npm run dev
```
